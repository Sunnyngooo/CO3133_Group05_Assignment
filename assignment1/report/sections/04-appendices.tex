\section{Reproducibility and Project Resources}
\subsection{Environment Setup and Dataset Preparation}
The commands below assume a \emph{separate source checkout} of the cited \texttt{a1} snapshot, with the working directory at the repository root. They are instructions for the current implementation, not evidence that new experiments were run while preparing this draft. Install Python 3.12 and create an isolated environment. On Windows:
\begin{quote}\small\ttfamily
py -3.12 -m venv .venv\\
.venv\textbackslash Scripts\textbackslash Activate.ps1\\
python -m pip install -r assignment1/requirements.txt\\
python -m pip install PyYAML
\end{quote}
PyYAML is an additional required dependency omitted from the current pinned list; its verified version is \textbf{TBD}. Fashion-MNIST is downloaded automatically when the data loader is first used. The EDA entry point can be invoked as follows:
\begin{quote}\small\ttfamily
python -m assignment1.scripts.eda
\end{quote}
Preserve the generated split file and use the same source revision and environment for all compared runs. The report branch was originally based on an older code snapshot, so report-only files should not be mistaken for the latest training implementation.

\subsection{Training, Evaluation and Checkpoint Reconstruction}
The following training commands correspond to the three architectures currently implemented in the cited source:
\begin{quote}\small\ttfamily
python -m assignment1.scripts.train --model linear\\
python -m assignment1.scripts.train --model mlp\\
python -m assignment1.scripts.train --model cnn
\end{quote}
Run identifiers take the form \texttt{<model>\_baseline\_<index>}. For example, if the first Linear run is assigned \texttt{linear\_baseline\_001}, evaluate it with
\begin{quote}\small\ttfamily
python -m assignment1.scripts.evaluate\\
\hspace*{5mm}--run-id linear\_baseline\_001
\end{quote}
The evaluation command must be entered on one line. Its run configuration and best checkpoint must already exist. The script saves \texttt{test\_metrics.json} in the run directory. LSTM and Transformer commands must wait for their model implementations; appearing in command-line choices does not make them executable models. Exact reconstruction of an observed score must be checked from retained artifacts rather than assumed from a seed alone.
