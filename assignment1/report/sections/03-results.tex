\subsubsection{Overfitting, Underfitting and Implementation Issues}
At the preliminary experiment's last logged epoch, training Accuracy exceeds validation Accuracy by 0.41 percentage points. Both loss curves decrease over the observed period. This short trajectory alone is insufficient to conclude that overfitting is absent or that the model is capacity-limited: the metrics are rounded, only one split is shown, and no independent repeat or test outcome is stored. A diagnosis for the current architectures requires their own histories.

Implementation issues relevant to interpreting this draft are the older notebook protocol, unfinished sequence-model modules and the lack of committed final-run artifacts. They limit evidence coverage rather than demonstrate a specific model failure. Runtime issues and verified fixes associated with the final experiment runs remain \textbf{TBD}.

\subsubsection{Parameter Counts and Model Configurations}
The three known counts follow directly from layer dimensions, including biases. Linear has 7,850 parameters, MLP has 235,146 and CNN has 220,234. The CNN therefore contains 14,912 fewer trainable parameters than this MLP, approximately 6.34\% fewer. This is a structural comparison, not an observed accuracy, memory or speed improvement. ReLU, dropout, pooling and flattening do not add learned parameters.

The implementation provides a helper for total, trainable and non-trainable parameter counts. The figures above were independently calculated from the current architecture definitions; runtime count verification for the final saved configurations is \textbf{TBD}.

\subsection{Comparison and Discussion}
\subsubsection{Effects of Input Representation and Inductive Bias}
The implemented architectures already make different assumptions about images. Linear and MLP consume flattened pixels, whereas CNN preserves a two-dimensional feature hierarchy and shares local filters. The MLP introduces nonlinear capacity without explicit convolutional structure. These design differences define what the eventual experiments should test; the current evidence cannot attribute a measured gain to any of them because a shared-protocol multi-model result is not yet available.

\subsubsection{Accuracy--Speed--Parameter Trade-Offs}
The current MLP and CNN have similar parameter counts, with CNN slightly smaller, whereas Linear is substantially smaller. However, convolution performs repeated operations across spatial locations, and equal parameter counts do not imply equal inference cost. A complete trade-off analysis must combine final test metrics with measured train/inference times and the documented hardware. The empirical comparison is \textbf{TBD}.

\subsubsection{Evidence for Hypotheses and Limits of the Comparison}
The stored EDA supports a near-balanced training subset, and the preliminary notebook output supports that a linear model can learn under its earlier setup. Neither observation decides the architecture-comparison hypotheses. There is currently no controlled evidence that the CNN outperforms the MLP, that nonlinear capacity improves over Linear under the current protocol, or that a sequence model is competitive. Those conclusions remain \textbf{TBD}.

\subsection{Limitations and Conclusion}
\subsubsection{Data, Method and Experimental Limitations}
This draft describes a controlled small-image benchmark and an implementation snapshot, not a completed five-model study. Its main limitations are unfinished LSTM/Transformer code, missing current-run artifacts and repeated trials, and unavailable per-class, qualitative and timing results. The preliminary Linear run cannot fill these gaps because it uses a different split and training configuration. Index-disjoint partitions also do not demonstrate content-level duplicate removal.

\subsubsection{Main Findings and Answer to the Research Question}
The completed work establishes a shared data-processing and checkpoint-selection pipeline, supplies EDA evidence and implements three architecture families. The stored training subset is nearly balanced, and the preliminary notebook reaches 82.91\% validation Accuracy under its earlier protocol. The main research question about comparative architecture quality remains unanswered. A final ranking and final test-based conclusion are \textbf{TBD}.

\subsubsection{Generalization and Future Work}
The next priorities are to complete the two sequence architectures, run all five models under the shared protocol, retain configurations/checkpoints/histories, and export test metrics, confusion matrices, prediction examples and timings. If feasible, additional seeds and a controlled representation or regularization ablation should assess stability and explain observed differences. Claims beyond Fashion-MNIST would require evaluation on data reflecting the intended deployment conditions.
